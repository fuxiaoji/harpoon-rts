## estimated 值清单

数据书不提供、由同量级推算的值（未列出的条目按同类默认处理）：

1. **全平台通用**：`cruise_speed_kts`、`turn_rate_deg_s`、`noise_db`、`vp_value`、`chaff`、`deck.capacity`、`deck.cycle_s` 均为 estimated。巡航速按最大速的 0.65–0.75 或舰型惯例；转向率按吨位/舰型；噪声按尺寸与 Acoust Cnt 世代；VP 按 DP 与角色；干扰弹数量除数据书明确的 Dosan 36、Hai Kun 24 外均为 estimated（Hai Lung 20、214 24、209 16、KSS500A 12 等为同量级推算）；`deck.capacity` 以数据书 Aft Pad 的停放数为准（仍属推断），周期 600 s 为 estimated。
2. **RCS 映射**：`Signature` 前半段（Large/Medium/Small/VSmall/Stealthy）映射到引擎的 `Large/Medium/Small/VerySmall`；Stealthy → VerySmall。不是估算，是枚举映射。
3. **潜艇最大深度**：数据书给 `Max Depth: Int III/IV/V`，未给米制值；按 Int III=200 m、Int IV=300 m、Int V=400 m 折算（Dosan 为 est. Int V → 400 m；KSS 500A/209 为 Int III → 200 m；Hai Kun 为 Int V → 400 m；Hai Lung 为 Int IV → 300 m）。均标 estimated。
4. **飞机续航**：`endurance_s` 由数据书的 Cruise Range ÷ Cruise Speed 换算，不是额外估计；甲板停放数按数据书 Aft Pad 数量。
5. **武器通用参数**：`pk`、`salvo`、`reload_s`、`min_range_nm`、SAM `directors` 数据书不提供，按内置泛化武器同量级推算（标 estimated）。`range_nm`、`speed_kts`、`damage` 尽量取 ANNEX C/D1/F 的印刷值。
6. **炮械射程换算**：ANNEX C 以 kyd 给出，按 1 kyd=0.5 nm 换算；76mm 用 20.1 kyd→10 nm，40mm 用 3.3 kyd→1.65 nm，20mm 用 1.4 kyd→0.7 nm，25mm 用 1.6 kyd→0.8 nm，35mm 用 2.2 kyd→1.1 nm。`damage` 取近距 `Dam` 值。30mm SMASH 用 5.5 kyd→2.75 nm，但卷内值写 2.5 nm（略保守，estimated）。
7. **未列入本卷的雷达/声呐距离**（estimated）：KR `kr_spy1d`；TW 的 US 系统 `tw_sps48e/tw_sps49/tw_sps55/tw_spq9a/tw_mk92/tw_sps67/tw_sqs53d/tw_sqs26/tw_sqr18/tw_sqs56/tw_sqr19`；所有 EO/IR 与机载雷达距离。`radar_air_long` 直接复用内置泛化条目（SPS-49 级别，200/36/80 nm）。
8. **未列入本卷的 SAM 射程**（estimated）：`kr_sm2` 75 nm、`kr_sm6` 130 nm、`kr_ram` 5 nm、`kr_rim7p` 8 nm、`tw_sm1` 40 nm、`tw_sm2` 75 nm、`tw_sea_chaparral` 3 nm；`tw_tien_chien_2n`、`kr_haegung`、`ph_vl_mica`、`ph_mistral` 取 ANNEX D1 印刷值。
9. **导弹制导路径**：引擎只有 `HomingAir/SeaSkimmer/WakeHome/TorpedoActive/AswBallistic/BallisticGun` 六种。`ph_spike_nlos`、`tw_rocket70`、`kr_hanwha_rocket` 的“直攻/火箭”路径用 `SeaSkimmer` 或 `BallisticGun` 近似；`kr_hyunmoo3c` 用 `SeaSkimmer`（巡航导弹）。这些是引擎语义映射，不是数据书原文。
10. **RIM-116/RIM-7P/Sea Chaparral/Mistral/VL Mica**：`ir=true` 只对真正的红外寻的弹（RAM、Sea Chaparral、Mistral、VL Mica）设置；RIM-7P 为半主动雷达，`ir=false`；SM-1/SM-2/SM-6/TC-2N/Haegung 为雷达/半主动，未设 `ir`。
