# 实时唤醒与推理预算：一次方法创新尝试及停止条件

日期：2026-10-21。性质：研究提案与条件命题，不是实验结果、完备新颖性审查或已成立的论文贡献。作者为本轮 Astra 方法子代理。已完整阅读根 `AGENTS.md`、`agent.md`、`plan.md`、`havedone.md`，以及本目录上级 `README.md` 和 `docs/research-realtime-m1a-20261021.md`。本轮仅新增此文件；未改生产引擎/服务、未读取密钥、未调用真实模型、未运行实战。主代理负责将核验后的阶段状态纳入根进度文件。

## 1. 结论先行

值得做的低成本候选是：**按“结果真正生效后的任务增益”联合选择等待与推理档，保留质量、延迟、旧计划运动及任务失效之间的联合分布。** 下文简称“有效完成值调度”。它是面向当前接口的有限动作元决策方法，不应把一个新的缩写或联合 `argmax` 当作理论创新。

目前没有证明这个方法胜过足够强的规则方法，也没有证据证明 D0–D4 必须使用 LLM。相反，D0–D2 很适合证明“不需要再次推理”的边界；建议的最小 D3/D4 也可以由 397 项有限枚举完全解决。因此首轮工作的正确目标是判断是否存在可测的预算收益和不可忽略的耦合，而不是保证新调度器获胜。

可争取、但尚未成立的具体贡献是：在黑盒、不可任意中断的同模型推理档下，以低成本估计**条件有效完成值**，在实际墙钟、有限总预算和部分观察下取得可复现收益；并解释哪些收益来自延迟尾部、质量与延迟的相关性、旧计划继续执行造成的可达性变化，哪些只是更多调用。单独任何一项动机都不是新发现。

## 3. 形式化：不能把推理时长当成一个独立罚项

隐藏世界状态为 `X_t`，已部署的持续计划为 `p_t`；在没有新计划生效时，世界按生产核心及 `p_t` 演化。本方历史 `H_t` 仅含合法观察、公开任务与本方命令回执。廉价监视器可读同一合法观察接口；其采样、计算和缓存均计入运行成本，不能给联合组独占额外情报。

空闲时的元动作集合为

`A = { wait(δ), invoke(L), invoke(M), invoke(H), hold_to_end }`。

`δ` 为固定监视步长，模型在等待时不被调用。一次调用从快照 `O_s` 开始，预算档 `b` 产生联合随机输出 `(P_b, τ_b, C_b, E_b)`：完整计划、端到端延迟、实际成本和错误状态。预算档不是实际推理 token，也不是 `max_tokens` 的同义词。最早生效时刻是 `e=s+τ_b+v_b`，其中 `v_b` 包括校验/入队/下一 tick；期间旧计划继续执行。初始快照年龄为 `a_s=s-time(O_s)`，生效时年龄为 `a_s+τ_b+v_b`。

任务 `j` 有公开截止 `d_j`、权重 `w_j` 和完成谓词。执行时间为

`T_j = e + travel_and_service(X_e, P_b, j)`，

不是 `s + τ_b + travel_and_service(X_s, P_b, j)`。即使 task revision 不变，`X_e` 已变化；revision 拒收只能覆盖离散失效，不能覆盖全部过时损失。迟到、解析失败和过期拒收均保留在样本里，其期间旧计划产生的收益也计入。

研究目标为 `max E[S_T]`，约束每局可支出的资源 `B`；`S_T = Σ_j w_j 1{j 在其截止内完成}/Σ_j w_j`。论文主要比较用相同硬预算上限和实际成本曲线。内部调度器可用 `S_T - λ C` 作为代理，但不得将软罚最优等同于严格预算可行；调用前按可核验的上限预留额度，没有可靠费用上限时只能称预期成本控制并另报超额。

精确的元决策状态可用 `(H_t,p_t,B_t,inflight,t)` 表示，或在模型已知时用对应 belief；不必假装存在在线可得的真实状态。睡眠会增加观察年龄，也可能获得新信息；一次昂贵调用还会占用单请求槽并减少未来资源。完整 Bellman 关系因此同时包含等待转移和不同随机持时的调用转移，是一个部分可观测的半马尔可夫控制问题。这里只给问题形式，不声称已求解最优策略。

## 4. 可落地的候选：有效完成值调度

### 4.1 有限数据、廉价特征、单请求

首轮只选真实可区分的两个预算档，第三档待校准后决定。输入特征 `z` 建议限于：

- 未完成任务数、资源冲突度、公开权重与最近任务 revision；
- 最紧截止的剩余时间、当前计划已完成/预计还能完成的任务；
- 按本方位置与当前站令推进 `δ` 后的可达性变化，尤其是朝目标接近还是远离；
- 观察年龄、近期相关 revision 到达频率；
- 剩余费用比例、剩余局长、是否存在锁存触发。

“可达性变化”首轮由只依赖本方已知状态的导航预测得到；如预测需要未知敌情，只能使用合法 belief/区间或将其标为未知。不得从裁判未来轨迹导出在线特征。特征本身若足以直接求出最佳任务分配，应同时运行那个无 LLM 策略，不能把它只藏在调度器里。

从开发集的相同合法观察采样不同预算回复，保存完整计划和实际 `(τ,C)`；对每个回复进行以下**不同用途**的分支评估：

1. 零推理延迟应用：估计该输出在当前快照上的任务质量，作为机制诊断。
2. 在测得的实际延迟后应用：旧计划照常推进，按真实生效位置及截止评分。
3. 若干预先固定的额外延迟：只测同一输出的时效敏感性；不得把这些结果称为不同思考预算的模型输出。

这是离线训练/诊断，允许事后裁判计分。所有在线组仍仅接收本方观察。一次真实响应的多个重放是相关样本，统计单位仍是原场景/对局，不能扩成虚假的 API 样本量。改变唤醒时间意味着输入观察也改变，不能把旧回复挪时应用当作“晚一点重新调用”的有效反事实。

用小型分箱表或受限深度回归树直接估计各档的**实现增益**，而非默认

`平均计划质量 × 及时概率 - 平均费用`。

调用 `b` 的局部值应近似 `E[后续任务分数 - 继续旧计划分数 - λC | z,b]`，包含真实联合采样和失效回复。所有分支用同一终止时刻及固定后续策略，避免较晚结束的分支有更长得分时间。原始数据不足的特征区间回退到开发集预先选定的强混合规则；不要在线调用另一个大模型给调度器估值。

### 4.2 等待值与全局预算

最低实现版本只做两步前瞻：比较现在调用 L/H，与等待一个 `δ` 后按届时合法特征调用 L/H 或继续旧计划。等待分支的特征转移由开发集条件转移表估计，包含新通知概率；禁止读取本局未来事件表。前瞻末端所有分支使用相同的简单续接策略。

伪代码：

```text
每个监视 tick:
    只更新本方 z、任务 revision 和触发锁存
    若已有在途请求: 不再请求，维持统一执行器
    否则:
        移除无法按预算上限预留费用的档位
        计算 V(现在 L)、V(现在 H)、V(等 δ 后自适应)、V(保持站令)
        以校准不确定性和切换成本作保守修正
        若候选优势不足: 使用预先冻结的强混合规则
        否则执行最大值动作
回复返回:
    用统一会话/revision/期限协议验证，再于下一 tick 生效
    更新真实费用；过期/错误响应也计费并留下轨迹
```

最多两个预算档、两个前瞻层和小状态表，不训练大模型、不并行调用、不依赖思维链或中途截断。`λ` 和预算储备规则在开发集固定；若用剩余预算比例动态改变 `λ`，必须给分开优化组同一功能。两步前瞻和预算影子价格都是近似，不能声称长局最优或稳定保证。

单次任务更新、没有后续相关信息、越早部署同一计划越好的 D1–D4 中，等待通常没有价值。它们只能校准预算选择；要主张唤醒优化收益，必须另外加入留出的多次相关/无关更新和全局资源竞争（D5/L1），或明确缩小论文主张。

## 5. 可证命题、反例与理论边界

### 命题一：精确分解与联合选择等价

令同一个合法元状态下的真实续接价值为 `Q(wait)`、`Q(L)`、`Q(H)`。先求 `b*=argmax_b Q(b)`，再比较 `Q(b*)` 与 `Q(wait)`，与一次 `argmax_{a∈{wait,L,H}} Q(a)` 完全相同；平局使用同一规则即可。

证明：有限集合的最大值满足 `max{Q(wait),max_b Q(b)}=max_a Q(a)`。同理，联合策略可写成阈值 `max_b Q(b)-Q(wait)>0`。因此“联合形式优于所有阈值”“两个模块必然劣于一个模块”均为错误主张。只可检验丢弃耦合信息的分解、有限模型类/训练目标的区别，以及估值精度与运行开销。

### 命题二：相同质量和延迟边际分布不足以决定有效收益

设计划质量 `Q∈[0,1]`，及时且仍有效的指示量 `I`，有效增益为 `QI`。恒等式

`E[QI] = E[Q] E[I] + Cov(Q,I)`

不需要独立性假设。考虑截止 2、无执行时间、等概率两种响应：

| 响应分布 | 两种 `(Q,τ)` | `E[Q]` | `P(及时)` | `E[QI]` |
| --- | --- | --- | --- | --- |
| A | `(1,1)`、`(0,3)` | 0.5 | 0.5 | 0.5 |
| B | `(0,1)`、`(1,3)` | 0.5 | 0.5 | 0 |

两个边际完全相同；独立相乘均预测 0.25，真实收益分别 0.5 和 0。若还有确定质量 0.25、延迟 1 的低档，则应在 A 用上述档，在 B 用低档。任何只使用这些边际的确定选择器无法在二者都最优；若上下文也完全不可区分，没有方法能在线区分。这是信息不足反例，不是本调度器已学会相关性的证据。

可检验预测：若真实数据中按状态和预算条件化后的协方差近零，保持联合分布的这一部分应没有收益；若优势只来自均值差异，也不能归因于该机制。

### 命题三：旧计划的运动可使最佳预算反转

抽象单任务，当前执行所需时间为 3，截止剩余 5。低档延迟 1、成功质量概率 0.6；高档延迟 3、质量概率 0.95。旧计划远离目标时，执行时间随等待变为 `3+0.5τ`；接近时变为 `3-0.5τ`（本例范围保持非负）。

| 延迟期间旧计划 | 低档完成时刻/期望得分 | 高档完成时刻/期望得分 | 最佳档 |
| --- | --- | --- | --- |
| 远离 | 4.5 / 0.6 | 7.5 / 0 | 低 |
| 接近 | 3.5 / 0.6 | 4.5 / 0.95 | 高 |

证明即将两档代入 `τ+travel(τ)≤5`。两种状态可有相同任务数、事件幅度、当前距离、观察年龄和截止，只有已部署计划的方向不同。忽略旧计划继续执行的阈值或难度预算器就会把它们合并。

令两类状态等概率、低/高成本为 1/3。上述条件策略平均成本 2、得分 0.775；任何不辨认方向的混合策略以概率 `p` 选高，其得分为 `0.6-0.125p`，成本 `1+2p`。在成本不超过 2 时其最好得分仍为 0.6；恰好成本 2 的独立随机分配得分为 0.5375。数值仅为反例构造，不能当作 Harpoon 或真实模型结果。若强阈值也使用方向及预算条件价值，它可以实现同一最优策略，这正是必须纳入的对照。

### 命题四：有限动作估值的局部保证及其局限

同一个元状态中，若对全部 `K` 个动作有 `|Q(a)-Qhat(a)|≤ε`，选 `ahat=argmax Qhat(a)`，则

`max_a Q(a)-Q(ahat)≤2ε`。

证明：设最优为 `a*`，则 `Q(a*)≤Qhat(a*)+ε≤Qhat(ahat)+ε≤Q(ahat)+2ε`。若候选相对基线的预测优势超过 `2ε`，真实局部优势为正。

这里的 Q 必须是同一续接策略下的同一目标，或真正的最优续接值；用各自随意截断的分数不满足前提。对于冻结的 `M` 个特征格、每动作每格 `n` 个独立同分布场景，若效用取值区间宽为 `R`，Hoeffding 加 union bound 给出 `ε=R sqrt(log(2MK/α)/(2n))`，同时覆盖的概率至少 `1-α`。这不是自动适用于重放切片、漂移服务或未见场景的置信带；小样本时界很宽。回归树上的泛化误差也不由该式保证。

本命题只是标准有限动作估计界，不能包装成新理论。当前未证明部分观察、非平稳延迟、策略改变状态分布、有限总费用下的长局 regret 或成功率保证。

### 两个必须保留的无 LLM 反例

1. D0 已有站令完成任务，得分上限 1；零追加调用脚本在已测 24 个实例全部达到上限。任何追加调用不能提升这些实例的分数，且产生额外模型成本。
2. D1/D2 输入明确公开唯一目标，确定脚本直接提交该目标。已有 5 秒控制延迟在已测实例均满分；LLM 的角色近似 JSON 转抄。可以验证接口和真实时延，不能据此证明模型深思能力。对未运行的所有种子不作未经证明的可行性外推。

建议的 D3/D4 也存在可精确枚举的无 LLM 策略。若它在真实计算开销计入后支配所有 LLM 方法，应报告这个结果；不得故意关闭它、少给信息或人为提高其费用来制造 LLM 必要性。

## 6. 最小 D3/D4：397 项完整枚举的多任务导航

### 6.1 统一任务与动作类

使用 3 个相同能力的本方导航单位、4 个公开到点任务；不引入武器、损害或隐藏敌军规则。沿用 M1a 的冻结核心、观察和 Goto 执行边界，固定同一航速、到点半径及转向/加速机制。新增的任务权重、分配/截止和共享路线执行器均属于公开研究设定，不冒充 Harpoon 原规则。

初始各单位按同一接口拥有持续站令。在随机且不可预知的事件相位，一次公开 4 个目标及权重。模型输出每舰长度 0–2 的有序任务 ID 列表；每任务最多分给一舰，允许省略，所有组共用同一动作类。共享执行器仅跟随路线、到点后切换下一个任务、公开到期后跳过过期任务；它不选择任务、不改变优先级、不替模型重排。每项只在它为该舰当前任务时入圈计完成，重复访问无额外分。完成事件按生产 tick 记录，截止当 tick 完成有效。

恰好分配 `r` 项任务时，3 舰任务数量向量的各分量为 0/1/2、和为 r；r=0..4 的向量数分别为 `1,3,6,7,6`。每个向量配 `4!/(4-r)!` 个无重复任务排列。因此总数

`1 + 3×4 + 6×12 + 7×24 + 6×24 = 397`。

按固定顺序枚举并在同一个本方可重建初态分支调用生产核心，得到**这个有限动作类内**的精确最优；不是整个 Harpoon 连续动作空间的最优。先核实没有隐含航速/自由改派权限差异。若允许多次决策，这个 397 项参照只是当前快照下一份完整路线的参照，不能当作未来随机任务的全知最优。

### 6.2 生成与配对，不按方法输赢筛选

冻结一个小的有限坐标网格和初始站令方向集合，从网格不放回选 4 个目标；权重从 `{1,2,3}` 独立采样。目标重名、输出顺序及单位 ID 随机置换；做几何镜像和旋转。旧站令方向同时包含接近与远离未来目标的情况，方向分布独立于预算标签；不只保留贪心失败的实例。有限网格范围在开发阶段根据实体可航行范围及任务时长确定，不能根据新方法胜率选择。

先用同一动作类的零推理延迟枚举得到完成所有任务的最小 makespan `T_phys*`。如果在冻结局长内不存在全任务可行路线，则保留并标记生成器诊断，修改生成器必须记录版本；不得无声丢弃对某方法不利的实例。

D3/D4 的单位、位置、旧站令、任务、权重和事件时刻完全配对；仅截止窗口不同。一个最小协议是所有任务共用 `d=release+T_phys*+W`：D3 使用宽松 W，D4 使用预设较紧 W 网格。W 从所有真实预算档在独立校准集的延迟分位数决定，并按固定模拟倍速映射；所有方法同窗。例：先冻结覆盖“短档通常来得及、长档处于边缘、二者均宽松”的窗口/延迟比，之后不看方法排名调窗。具体秒数等真实校准后填，不能用脚本 5/180 秒直接当模型预算值。

`T_phys*` 用于生成公开截止，不作为模型输入的答案提示。截止不是简单“留给模型的思考秒数”：因为旧站令继续运动，延迟后的可达时间必须重新按生产核心计算。

### 6.3 两种 oracle 和三种分数

- **诊断 oracle**：完整枚举当前合法信息，计算时不推进对应分支；报告数学上界，明确其免时间代价特权。
- **部署枚举器**：相同枚举真实运行，计 CPU、墙钟延迟，运行期间世界推进；只有这组可作为无 LLM 实际竞争者。若可用缓存，缓存构建成本和各组信息/训练权限须公开。
- **模型计划质量**：在零推理延迟分支得分；**有效得分**：真实延迟应用后得分；**过时损失**：同一输出在两分支的差。差可能为负，不能强行截零；早/晚生效的运动轨迹可能不同。

为分清“内容好但迟到”和“本来就选错”，每个模型输出都保留路线、逐任务完成时刻和拒收原因。定长 JSON 输出约束统一；不要通过让高档写更长解释制造迟到。

最小 D3/D4 只含一次更新，适合证明复杂度和截止之间是否有真实交互。如果两个预算档在暂停分支都近乎最优，这个任务就缺少推理质量差异，应如实判为预算研究 no-go；不靠增加无关提示长度把任务做难。要研究何时唤醒，后续 D5/L1 应有独立生成的多次更新、无关通知和有限全局预算，且任务族整体留出。

## 7. 必须击败的基线、关键消融与公平成本

第一阶段对照只保留能够回答机制的问题：

| 比较 | 共同条件 | 要区分的解释 |
| --- | --- | --- |
| 最佳固定频率×预算；强人工事件+最长休眠 | 同信息、同预算档、同开发搜索资源 | 改善是否只是一个弱基线或更多调用 |
| 预算感知的强阈值 | 允许使用旧计划方向、截止、剩余预算及每档延迟 | 新方法是否超出手工把必要变量加进阈值 |
| 分别调优后组合 | 预算器可读同样完整特征；记录其训练目标 | 联合训练/价值估计与模块组织差别 |
| 精确分解实现 | 与联合组复用完全相同 Q 表 | 应逐动作相同；不同即实现缺陷，而非创新证据 |
| 共同非 LLM 规划器 / 实际部署枚举器 | 同合法动作、同真实执行协议 | LLM 是否对该任务有独立价值 |

最关键消融按优先级为：

1. 保留全部特征和样本，拿掉旧计划在等待/推理期间的推进，只按当前位置估计可达性。检验命题三的实际影响。
2. 在每个同质特征格、同预算内打乱“计划质量与测得延迟”的配对，保持边际分布。该项只能在离线预测/控制回放中做，不改变真实 API 回执；检验命题二的影响。随机化以原场景为单位，不能把额外重放当独立样本。
3. 使用完整延迟分布对比仅均值，区分尾部风险与质量相关性；第 2 项不替代此项。
4. 去掉等待的信息价值与未来预算影子价格，分别检验即时贪心和预算耗尽机制。
5. 暂停时钟、实测墙钟、独立固定延迟网格分别报告。暂停会改变轨迹，作为机制对照，不混成真实部署主结果。

成本匹配使用若干预先冻结的每局硬上限。输入/输出/可得 reasoning 用量、调用次数、实测墙钟和金额分别列出；CLI 没有可核验计费回执时金额标为缺失，不能用 CLI 次数冒充美元。调度器、监视、规则生成、重试、失败/取消、初始化和枚举器计算均记账。固定基线允许不花满预算，不要求它为了“等费用”做无用调用。比较完整 Pareto 曲线及相同上限下最强开发配置，不使用测试集逐局挑最好基线。

开发校准调用按时间块交错，避免 API 负载变化与方法绑定；冻结分析后按场景模板/几何结构留出，另留种子。主要分析单位为场景/对局。由先导样本估计配对差方差并按预设最小关注效应做功效分析，不能先决定小 n 再把未显著当等效。只换随机种子不算跨任务泛化。

## 8. 具体 go/no-go 门

以下是建议在真实模型数据揭盲前冻结的门，数值是研究决策阈值，不是已观察结果。若需改动，写入新协议版本，不追认旧批次为确认实验。

**G0，接口门。** 同模型低/高档的设置能由请求审计确认；延迟、用量及错误可记录，真实时钟持续推进、旧回复拒收和命令重演通过。若“档位”仅是提示措辞，或接口忽略设置，停止推理预算主张。

**G1，预算收益门。** 在独立开发 D3 的暂停分支，较深档相对浅档存在至少 0.05 归一化分数的正向效应目标，并估计配对区间；同时 D4 至少一档窗口出现可测的迟到损失。正式是否成立以足够功效的留出检验为准。若两档均达到精确 oracle 的 0.98 以上且差异被预设等效界支持，则不继续把它作为预算质量任务。若质量从不改善，只能研究节省计算/反过度推理，不能宣传双向权衡。

**G2，耦合门。** 先检验允许使用全部相关特征的强阈值。联合方法至少在两个留出结构族、两个预设预算上限上，主要得分相对最强可部署简单基线的配对 95% 区间下界大于 0，且点估计达到 0.05；或在预先冻结的等效界 ±0.02 内保持得分并减少至少 20% 实际模型用量。两条只能预选一条作主要成功路径，避免事后择优；其余为探索。

**G3，机制门。** 至少一个预先指定耦合消融在留出数据上降低效果，方向与日志中的失效类型一致；不是仅因消融少了特征或调参资源。若精确分解与联合组不同，先判代码问题。若强阈值/部署枚举器相当或更好，停止“新联合算法优越”主张，保留有价值边界结果。

**G4，成本与外推门。** 等成本优势不能由更多实际请求、不同底层执行器、额外合法信息或服务时段解释。必须有实际墙钟确认，固定延迟结果不能替代。只在本平台/一种模型上成立，则论文结论限定该范围；不能把救援/机器人写成已验证应用。

**继续理论创新的触发点。** 如果 G0/G1 成立但 G2 失败，且预测误差/长尾/分布变化有明确证据，可以针对“如何从少量样本估计状态条件下的有效完成分布”或“预算有限时怎样估计等待的信息价值”继续方法研究。若没有可测质量差异、简单枚举已支配、或耦合消融无影响，先停止扩场景和大规模模型花费；不能用新名字代替未出现的研究难点。

## 9. 本轮实际核验

本轮执行了一段不写盘的 Python 检查：枚举动作数为 397；命题三两种状态的低/高期望得分分别为 `[0.6,0]` 与 `[0.6,0.95]`；命题二两种联合分布的有效期望为 0.5/0，协方差为 +0.25/−0.25。它们验证的是构造算术及计数，不是模型表现。

待验证项包括：真实档位校准、预算质量曲线、导航生成器与共享执行器、部署枚举器开销、条件估值泛化、D5/L1 的唤醒价值，以及完整的相关工作排重。当前可以交付严格的候选和可证伪协议，不能交付“已出现论文级创新”的结论。
