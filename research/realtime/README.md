## 场景与目标

三个模板使用相同的原生 Harpoon `Scenario`、内置通用舰种、18 节初速、初始向东航路和关闭的自动开火。另一个阵营的静止控制单位在 5000 海里外，不承担任务且不可见。实验到点任务独立于原引擎击杀计分。

| 模板 | 公开任务及变化 | 时间与评分 |
| --- | --- | --- |
| D0 | 按初始站令访问 (3,0)，无改派 | 1200 秒内进入 0.12 海里半径区域 |
| D1 | 在种子确定的 97–197 秒收到新到点任务；目标位于原计划该时刻位置的南/北 0.6 海里 | 更新后 900 秒内进入新区域；旧目标完成不计新任务成功 |
| D2 | 初态、事件时刻和新目标与 D1 一致 | 仅将更新后窗口改为 180 秒 |

97–197、0.6、0.12、900/180 都是仪器验证用实验设定，未由真实模型延迟校准，不是正式论文冻结参数。该任务测到点访问，尚未测持续巡逻覆盖、多任务规划或交战效果。D0 是不需要额外调用的负对照。

## 时间与接口

- `injected`：引擎每秒 tick；结果在观察后指定模拟秒可用，适合确定性控制。即使延迟参数为零，也至少跨一次 tick 后接收，再于下一 tick 生效。
- `wall`：引擎按单调墙钟目标节拍推进；脚本响应由独立线程真实等待返回。`--tick-ms 2` 表示每模拟秒对应 2 毫秒墙钟，5/180 模拟秒对应线程等待 10/360 毫秒。线程等待时舰艇持续移动；这不代表真实 LLM 的服务速度。
- 相同 tick 的顺序：公开任务更新 → 验证并执行此前排队命令 → 生产引擎步进 → 观察/评分 → 接收并校验响应 → 检查唤醒并发出请求。下一 tick 才允许新命令生效。
- 单个在途请求；等待期间的触发合并锁存为一次待办。固定周期采用 T0 起算的 60/300/600 秒网格；T0 已有相同站令，诊断脚本不产生初始 API 调用。纯事件只监听公开任务 revision，不含隐式定时兜底。hold 从不额外调用。
- 本方规划输入只有生产 `observe` 返回值、当时公开任务、已生效任务 revision。场景标签 D0/D1/D2、未来任务时刻、未来目标、模板 RNG 与裁判 World 不传给规划器。三模板公开场景名相同；任务期限只在任务出现后可见。
- 回复绑定原任务 revision；任务变化导致旧回复失效。响应校验与下一 tick 生效前均复核 revision 和期限。截止时刻到点计成功；截止后到点、旧任务完成均不计。
- 每次请求保存触发、取观察/发出请求、响应、校验和实际生效的模拟/墙钟时刻。触发锁存保留最早触发时刻，能够单独计算请求排队时间；监视检查次数与脚本调用数分别记账，没有将它们转换为虚构 token 或金额。

## M1b：真实预算与 D3/D4 小任务

`llm_client.py` 经已登录 Codex CLI 发出 `gpt-6.1-sol` 的 low/medium/high 真实请求，采用统一结构化输出、禁用工具并审核执行事件。它不读取或复制认证文件，不保存 reasoning 文本；响应、端到端耗时和提供方用量保存，金额缺失。工作目录必须为空的随机 UUID，避免目录名泄露场景或实验档位。六项客户端单元测试覆盖错误分类、工具拒绝、文本剔除及动作校验。

`realtime_assignment.rs` 在 160 模拟秒公开四个任务，由三艘本方舰船分配访问，每舰最多两项有序任务，每任务至多一次。目标由种子生成，权重置换 1/2/3/4。D4 截止为发布后 180/240/360/480 秒；D3 仅增加 300 秒。截止后到点不得分但继续导航；空路线沿原站令，不自动跳过过期任务。该实际生成器与 `theory/astra-proposal-20261021.md` 中建议的未来网格/共同截止/跳过规则不同，不能混称同一冻结协议。

同一请求输出在 0/60/180 秒和 `ceil(实测墙钟秒×5)` 延迟分别由生产核心重新运行。旧站令在延迟期间继续，命令下一 tick 生效。它测内容质量和时效，**不测改变唤醒时间后的新观察、新输出或多次闭环策略**。一个响应的多种回放不是多个模型样本。

有限路线类共有 397 项，提供离线参照并记录枚举耗时。`--public-input` 另支持仅凭三个完整本方单位、公开任务和站令重建无敌军预测世界；限制为本次无损导航类。后补传统基线实测进程计算耗时后部署所选路线，不免费使用离线 oracle。5 项 Rust 测试及 4764 项公开预测/原裁判计分一致性检查通过。

模型批为两个种子×两窗口×三档，共 12 请求。三档零延迟都达到总有限最优 33 分；实测延迟回放为 33/31/28，传统枚举计耗时后为 33。两配对种子不足以证明等效或普遍排名。当前任务出现质量饱和，不能支撑深思收益或联合调度优越性；M0 定向排重、M1 复杂任务有效性和实时模型闭环仍未完成，D5、成本匹配、长局及留出确认待办。
