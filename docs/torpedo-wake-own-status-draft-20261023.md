最小实施顺序：

1. 先以私有 `own_view(world,side,unit)` 暴露源鱼雷管/重装状态。跨方、无源装填的平台返回无对应状态；保存恢复不得重置重装截止时钟。真实发射后管空、储备装填及未切线拒装均有observation测试。源储备、装填中武器、管内武器与旧聚合ammo分别标清，不能向用户展示彼此矛盾的“可发射数”。
2. 增加带来源的Wake发射/尾流几何绑定，先写真实“未交叉不锁定”“交叉后75%闭合”“25kt+90°规避”的失败测试。未知附件参数或几何参数须明确source/scenario_assumption，不补猜测默认值。
3. 接穿越舰诱偏与Gen3/4拖曳双骰；每个真实事件只掷一次并缓存到Referee。诱爆必须真实调用`consume_towed`且退役鱼雷；通过抗骗才允许第二枚独立终段骰。两阶段结果、目标切换和余程均保存恢复。
4. 接Wake专用500yd/180°再攻击。未解决的Poor来源冲突继续保存完整弹体、既有骰和证据待裁，不重掷。

本方弹体视图有独立真实缺口：当前`observe.rs::observe`的units仅按本方且alive过滤，仍把切线/非双线导鱼雷的真实pos/course/speed投影给发射方。即使原始placement/terminal事件已隐藏，也可通过真实转向与弹体消失推断错位/寻的。下一包须先加入`Observation.units`反事实失败测试，再依据源反馈资格投影弹体；本方发射声明和源管状态不等于可实时获知水下弹体真实位置。这一项未包含前包raw事件可见性验收。

来源未给足而不能自行定值的边界：

- `R-TORP-WAKE-OFFSET`：PDF110的离轴表列Gyro1/2、Passive、Act/Pass、Wire/DualWire、Shkval，未列Wake。当前不能凭名称给Wake套90°/120°；需要精确附件/合法源绑定或明确作者条件。
- `R-TORP-WAKE-GEOMETRY`：上述段落未给尾流宽度、持续时长及开局前历史。不能默认为永久无限长尾流，也不能猜10分钟消散。若实现以历史线段为RTS适配，必须把有效几何/时间作为显式来源或作者条件；不确定部分保留待裁。
- `R-TORP-WAKE-VSMALL`：穿越舰映射只写Small/Medium/Large；VSmall穿越舰不能无据自动视为ACM1。
- `R-TORP-WAKE-MULTI-TOWED`：多个同时有效Gen3/4拖曳器的抗骗次数/选择优先级不在上述文字明确；不可静默将每个概率相乘或取最高代便称完整实现。
- `R-TORP-WIRE-REPORT`：双线导明确可收状态/目标位置，但单线导反馈粒度、失锁后的报告保鲜及精确位置误差未在此给出。本方视图不把整个Flight/真实目标实体直接序列化。双线导也须同时满足线仍连接、武器真实捕获目标，不能仅因配置DualWire就暴露敌方真坐标。
