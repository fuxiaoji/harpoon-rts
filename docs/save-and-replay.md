# 本地存档与可验证复盘

2026-10-20，Rust RTS 增量实现。规则核心、装备性能、命中/探测概率未因本轮修改。

## 使用

大厅和指挥台都有“存档 / 读档”。填写名称后“保存并暂停”，从列表选择存档读取。读取会替换当前局，先保存需要保留的进度；恢复后为0倍，状态机开关与内部记忆恢复。LLM参谋的记忆、历史报告及建议保留，但自动运行与启用状态关闭，需手动重新启用。

作战终局自动写入一份完整存档。大厅复盘列表、复盘页档案列表及存档窗口均可打开已完成局。进行中局的双方完整档案拒绝向浏览器提供。原有JSON/GZIP观察档案导入、导出及三视角播放器保持兼容。

“校验命令重演”在后台从该存档记录的初态执行所有原始命令与控制器审计事件，比较完整World摘要和全部事件序列。它不替换当前战局。复盘筛选新增“下达命令”“AI指挥意图”；命令只表示下达，实际执行以发射、回收、损伤事件核对。倒带及阵营切换清除未来与另一方的命令。

## 保存范围与精度

2026-10-21第二版还保存FSM/LLM共用的资源/效果账、任务期限、失联重获计时、支援替换冷却、出生来源及EW/ASW任务归属。新鲜决定（包括hold）只续期仍有效的受管任务；读档保留剩余期限，不重新发放600秒。飞机短暂失联保留有限搜索期并禁射。人工命令解除本单位的管理器租约；完整手操应关闭对应席位FSM。新增跨进程T780→T1080对照，完整私有状态与后续战局相同，见`ai-completion-20261021.md`。

- 保存格式 `harpoon-server-save` v1，当前写入兼容标识 `harpoon-rts-save-20261021-4`；本版还读取并校验`harpoon-rts-save-20261021-3`、`harpoon-rts-save-20261021-2`、`harpoon-rts-save-20261021-1`和`harpoon-rts-save-20261020-2`历史档，旧程序不保证读取新档。World包括RNG、冻结数据库、双方情报、航空/弹药/损伤/任务状态；另存待执行队列、TacticalStaff各单位/突击波/分类记忆/节奏、分侧LLM记忆，以及初态、命令记录、完整事件和双方同步观察。21-3增加机群共享状态和执行器定时发射队列；21-4增加持续自动防空预算。排队不算实际释放，恢复后仍需重新核验本方航迹、弹药和期限。
- `serde_json/float_roundtrip`保证JSON读回保持浮点位值。负载有FNV64完整性校验；它用于发现损坏，不是签名或加密。`create_new`临时文件、`sync_all`、原子重命名，失败不会替换已有存档。版本、兼容标识、校验失败拒绝载入，当前局保留。
- 默认 `tmp/saves/`，可用环境变量 `HARPOON_SAVE_DIR`改为独立持久目录。存档包含裁判真态，不放进web静态目录，不经玩家API下载。保存/读取/验证/完整归档接口仅接受loopback连接，忽略伪造的转发IP头；本项目整体仍是可切换阵营的本地热座版本，尚未实现多人身份权限。
- 普通作战与实验导演循环按每模拟秒捕获所有事件，在恢复4096条玩家环形尾部之前复制；双方海图每30秒同步采样，并记录最终时刻。播放器保持最近非未来样本，不插值。命令与事件按真实模拟秒定位；这不等于播放器存了每秒World快照。
- HTTP/WS观察附带只随新局/读档/课程切换变化的会话修订号。另一窗口读入同想定的较早存档时，现有页面也会清理旧航迹/事件并接收较早tick；旧会话迟到帧被丢弃。

## 边界

2026-10-21长局验收：六小时双FSM复盘早期实际190,176,775字节/313,570条命令，扩编版253,056,203字节/430,619条命令，热开场版274,071,261字节/459,554条命令。原100MB/10万命令限制会阻止打开。播放器现按原文件及解压后均320MiB、最多50万命令作有界读取与校验，仍保留单位/事件/隐私检查；没有裁掉命令或战报。大档案在桌面浏览器实测，低内存设备仍需按实际资源评估，不承诺任意规模流畅。

训练仍使用课程内存检查点，本轮完整存档对训练及正在规划的LLM/导演窗口明确拒绝。保存并非每秒自动备份；手动保存或终局自动归档之后才能跨进程恢复。强制结束未保存的进行中进程仍可能损失进度。

兼容标识不是所有未来版本的迁移承诺。改变裁决语义或状态结构时必须更新兼容标识/迁移器并重新运行重演验证；保存中的冻结数据库不会被新进程启动时的卷数据库覆盖。旧Python原型存档不能导入此格式。独立旧 `/api/agent/duel`、`/api/selfplay` 仍有各自产物，未伪称为当前局完整存档。

## 验证入口

`cargo test --workspace --all-targets --locked`、`node --test tests/*.test.cjs`。`scripts/check-persistence.py <专用测试服务URL> <该服务存档目录> <输出目录>` 会替换该测试服务的当前局，禁止对玩家服务使用。它验证队列/FSM续跑、双方面相等、版本/损坏拒绝、终局自动归档、同步采样、事件连续和隐藏字段排除；跨进程验证、浏览器QA与真实模型CSG对局的证据在 `E:/CodexBuilds/harpoon-save-duel-20261020/`。

接口：`GET/POST /api/saves`、`POST /api/saves/:id/load`、`GET /api/saves/:id/replay`、`POST /api/saves/:id/verify`、`GET /api/replay/current`、`POST /api/replay/verify`。本地暂停裁判接口 `POST /api/advance` 接受本方side、最多16条commands、intent、1–300秒ticks；超限整批拒绝且不推进，FSM对手仍按30秒决策。回执为观察层合法性校验，武器射程/冷却等仍由真实引擎裁决。

2026-10-21执行可靠性更新：`/api/advance`还必须提供作者据以决策的`expected_tick`、`session_revision`和本次唯一`plan_id`。前两项来自`/api/state?side=Blue|Red`；`plan_id`为1–96位ASCII字母/数字/连字符/下划线。字段缺失400，旧时间/旧会话/已消费ID为409，拒绝不入队、不推进、不写意图事件。读档或新局后须重新观察。成功响应新增`plan_id/start_tick/end_tick/accepted`，旧`applied`字段继续作为观察层接收列表的兼容别名，仍不证明实际释放。最近256个ID按阵营隔离；更早原始请求仍因时间绑定而拒绝。

外部模型请使用`scripts/side-player.py --url http://127.0.0.1:专用端口 --side Blue --output E:/某个记录目录 observe`生成观察与带版本的空计划，保留计划身份填写命令和公开brief后，以同一前缀参数执行`advance <计划文件>`。客户端不会替旧计划填入新时间，也不会自动重试可能已被接收的写请求。接口是本地裁判接口，与玩家分方观察范围分别约束；该脚本只读取所选侧观察，保存原始请求/回执。
