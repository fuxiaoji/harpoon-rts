# 损伤引擎 v2 实施与验收（2026-10-22）

这次已经修改当前Rust生产执行路径。新建想定默认使用`hv2026-rts-v2`，旧World没有规则身份时仍为`rts-legacy-v1`。这是已核子集的实现版本，**不是全书录入完成声明**。逐项状态见[80项实施台账](damage-rule-acceptance-20261022.md)及[JSON](damage-rule-acceptance-20261022.json)。10月21日审计文件保留其历史状态。

## 已落到执行链的改动

- 稳定命中身份、同tick命中账本、命中去重、逐骰日志与受损方可见性；伤害按附件固定普通DP，另外结算附加关键、自动火灾及普通比率关键。多枚同秒命中不再复用损伤随机子流。异种命中的普通关键归属按DP权重抽选，属于明确RTS改编。
- 转录11个关键损伤列及11×6比率表；已核航母/两栖航空舰按航空舰船列。星号部位、Pen、舰体装甲与局部CHP进入判定。不能把小型直升机甲板当成航空舰船。
- 已核舰卡使用原DP/航速断点；剩余DP≤25%限制武器、潜艇上浮与航空勤务。F/G普通DP使用滚动180秒窗口判2倍DP沉没，不跨战术时长累积。
- Yu-6/10区分对舰141/对潜100，Yu-9为128/91；触发/感应引信分开，浅触发命中用舷侧装甲，深触发才消耗TPS。福特两舷315容量分别保存；同一区不能再次保护。首尾、尾流及潜艇耐压壳程序已接入，但并非全部条件组合都已验收。
- 舰桥失能保持原运动/延迟新航行令；舵卡死、失灵、解卡尝试；电力与单个传感器失能实际影响移动、探测与开火。潜艇电池/AIP/核潜艇混合行、耐压壳穿透与浅处逃生窗口有独立案例。
- 甲板首/尾损伤分别影响放飞/回收；机库只抽存放的ready/cycling飞机，逐架火灾有独立身份，排除在空机。航空油弹损伤接入火灾、殉爆、注水和惰化；没有假造真实甲板停放位置。
- 火/水按原DP百分比及各自起始时钟结算；普通首次540秒、随后1800秒，水下攻击进水及小艇按立即规则。损管先于当期二次损伤，一次D10管全部火、一次D10管全部水。抽调武器组停火，1800秒后降低有效严重性；失控火灾累计殉爆风险、注水防殉爆与倾覆程序已有执行。
- 新补浮航潜艇的开火目标域、1.2/1.4/1.6等比率浮点边界，以及严重进水潜艇首次损管无效后必须浮航。水面舰/浮航潜艇致沉后按D10×10分钟倒计时；水下潜艇、殉爆/龙骨断裂等立即沉没例外独立处理。倒计时不因读档重掷，击沉记账在实际沉没时发生。
- 普通LLM提示现在包含规则身份、本方功能损伤、武器/传感器失能、最低投放高度和甲板可用性，说明损管代价。50米可作为突防高度，释放前必须升至相应武器门槛；不能把旧提示中的50米直接当成全部武器合法投放高度。

## 明确的RTS改编与阻断

秒tick取代桌面阶段；小艇滚动180秒避免固定回合边界套利；连续转向用原45°→15°比率；新导航命令只延迟一次，不每秒重复延迟已接受的航路。TPS用左右舷各3个抽象分区，点模型通过D3或显式碰撞区选择；溢出进水依据Enterprise例解释。损管变化按比例分给各次火水，但不改变各次首次损伤期限。完整改编条目在规则JSON的`adaptations`。

第三代PRH关机命中倍率没有从第二代擅自继承1/4：此分支进入`pending_adjudications`，保存完整末段弹体、目标与时间，不掷命中/未中、不造成隐藏伤害，受损方日志显示待裁。已核的辐射目标发射、同一目标雷达改调谐、末次辐射位置与空爆损伤仍可执行。见R-027。武器关键命中缺甲板上/下位置时也会阻断该殉爆DP，不能把位置猜成舰内弹库。

聚能装药的英文PDF129写的是骰值+20，不是成功阈值+20。本轮按字面修正并记录原骰、修正和最终比较；没有按现实直觉反改规则，见R-029。目前已核武器元数据未启用该标志。

## 仍未结案

80项实施台账中，许多是已测子集，仍有未实现及待裁项。尤其是：

1. 全附件平台尺寸/年代/装甲/弹库部位与所有武器变体未录齐。未核平台仍有通用回退；不能把整个v2称为严格原书模型。舰射YJ12高空转末段距离无已核值。
2. 炸弹投放/穿透/自动甲板关键、远射大炮与完整空爆分型；潜艇轻度表虽转录，近失/区域武器流程尚未贯通。
3. 指挥仪、弹射器/升降机、完整局部火控与断电例外；甲板吞吐率、真实停放飞机、全部挂载与燃油模型。
4. 风向与火灾照明、轻微潜艇火灾通气、邻舰援助、货舱、小艇人员与全部浮力组合、潜艇舵深度控制和超限潜深风险。
5. 战后6/12/24/48小时修理、复燃/补片，损伤后的RCS/声学特征、人员转移、完整水雷/核效应/搁浅，旧Python表错误。
6. 其他基础章节的完整防空通道/三秒、空战/探测/火控/武器流程及机场港口组件仍要独立补齐；此次没有改编现实基地部署或运行新LLM对局。
