# 电脑与平板指挥界面改造

对象是需要同时管理航母、护航舰、潜艇与航空任务的玩家。首要操作是找到编队、知道谁在执行什么、给任务并随时接管。独立设计审查另见`frontend-hci-review-20261022.md`；规则引擎仍按独立台账继续。

保留现有海图色系：深海底`#040b13`、面板`#0a1c2b`、文字`#dcecf3`、蓝方`#4bcaff`、命令提示`#f2b660`、危险`#ff6266`。中文控制和舰名用微软雅黑/系统中文无衬线，等宽字体只留给坐标、模拟时间和型号。用户已要求优先电脑/平板，手机端暂缓。

布局保持海图主导，右侧从上至下为舰队选择与组令、当前任务/单位、按需细调、AI辅助配置；AI面板不占用找船前的首屏。平板横竖屏均保持时间、地图和选择可见，侧栏独立滚动。新增控制按44px左右触控目标设计，不依赖悬停或键盘。

交互顺序：浏览海图 → 多选或选编组 → 明确选择航行/任务模式 → 海图指定 → 显示排队/实际执行。空白处浏览不发令；群体航路保留相对位置并清理冲突站令。保留单舰细调。键鼠支持Shift选择、编组快捷键；平板有显式多选与编组按钮。

自动辅助分为保留当前任务/自卫的底层执行、玩家明确授予的单位托管、整席托管。人工接管后，上层FSM/LLM不会下一窗悄悄改回，只有玩家恢复辅助才重新授权；接管不会关闭基本自卫和燃油安全。任何自动程序只读取本方合法观察。

中文显示名与底层ID、存档、模型使用数据分开：列表/地图/详情/武器菜单使用统一名称函数，原始名与型号留在悬浮信息和详情；未知自定义名称不猜译，避免把识别不足的敌接触翻译成确定舰型。

验收：1600×1000、1024×768、768×1024真实CSG多舰页；组令目标归属、选择切换、浏览误触、手动覆盖保存及FSM下一窗、基础任务仍执行、中文名称不改ID和旧档；独立浏览器实操与截图分别核验。
