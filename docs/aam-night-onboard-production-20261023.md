# R-048 夜间缠斗本机探测条件

本包接续此前747通过的独立验收批，不改旧冻结程序与日志。先按规则Skill检索RAG的夜间与`9.4.8`，中文命中`core_rules_cn:p104:c02`；原版视觉依据为English Jan2026 PDF104/印刷9-3，图为`artifacts/rules-all-20261023/aviation/p104.png`。来源规定：夜间对MR≤0.5目标可以使用枪和导弹；对更灵活目标，仅在本机radar或IRST探测后可以发射导弹，枪战禁止；云内不能缠斗。既有夜间枪战与云门保留，本包仅补AAM的本机条件。

此前AAM实际发射只验证共享的已分类可用接触及本机雷达型号，没有查本机是否探测目标。`aaw.firecontrol.tracks`虽记录observer/sensor/target/last，但原`record_detection`只有显式裁判夹具适配调用，真实源传感器没有消费；融合每方最佳接触也会丢弃其他本机和其他传感器的成功证据。检测模块现从每个成功扫描保留独立三元组，联系人更新后逐条记录来源轨迹，不从共享接触生成本机轨迹。

`aam2026::fire_at`在扣弹和创建弹包前消费本机轨迹，仅接受本机已装且仍正常工作的Radar，或有来源且模式明确为IRST的Ir接收器；他机、共享簿、视觉、FLIR和ESM不代替本机条件。夜间MR>0.5且没有合格证据时，真实人工/自动发射入口均拒绝而不扣弹。IRST替代雷达、MR恰0.5、白昼和缠斗外仍按来源保持其例外。成功发射事件只记己方所用传感器，不新增目标真实MR或敌方设备明细。

真实源扫描位于每秒tick的命令之后。因此当前或紧邻上一tick的成功轨迹可供下一次命令使用；这一tick桥接是明确记录在`aam-2026.json.night_dogfight`的RTS过程适配，不宣称原书给了额外探测保留期。更早、未来时间、停机、雷达静默或受损接收器不满足当前本机证据。IR模式是静态来源/想定配置；将来若新增运行时切换模式，必须保存扫描时模式，不能把旧FLIR轨迹改配置后当成IRST成功。

先失败记录为`artifacts/rules-next-20261023/validation/own-sensor-night-red.log`：无本机证据时仍错误释放，以及真实雷达成功却没有本机轨迹，均实际复现。第三个红例的MR0.5边界原用F18/AIM9X2，AI、速度、签名修正把最终指数推过已印刷的5.5，被既有禁止外推正确拒绝；边界改用同一duel中已核的J15/PL8B反向攻击F18 VLow MR0.5，不修改源概率或表上限。人工加入的IRST/FLIR资格夹具明确是`scenario_assumption`，不声称真实F/A-18配装了该IRST。

新增三项`real_night...`测试覆盖共享/他机/视觉/FLIR拒绝、真实本机雷达成功与过期/停机/静默失效、IRST替代和全部适用例外；接受与拒绝均比较完整World保存续演。`artifacts/rules-next-20261023/validation/fourth-core.log`记录AAM12项全部通过（原9项加本包3项），检测56项亦全通过，包含多observer、多sensor成功证据不被最佳融合丢弃的生产回归。该批另有鱼雷straight红例，不能把整份日志或全工作区叫作全绿。本结论只覆盖R-048已核本机子集；未经来源观察的精确敌方BDA、完整云内/外局地条件及整本规则仍未完成。
