# 本地指挥大厅

根路径 `/`（`web/index.html`）为统一大厅。原完整战术指挥台移至 `/command.html`，复盘仍为 `/replay.html`。一键启动打开根路径，自然进入大厅；现有服务按请求读取静态页面，无需重启玩家服务或重建Rust。

## 玩家流程

| 入口 | 行为 |
| --- | --- |
| 继续指挥 | 读取真实当前战局、模拟时间、倍速与训练会话；进入原指挥台，不新开局。课程会话始终回到蓝方训练席。 |
| 作战任务 | 只列当前服务存在的任务，训练想定放入学院；搜索、分类、简报、时限、初始单位数量、规则参谋状态、蓝/红指挥席、可选随机种子。 |
| 训练学院 | 从权威课程API读取8课与真实结业记录，预览原有目标，开始或继续当前课程。 |
| 战局复盘 | 读取本地档案清单，打开已有双盾实操复盘；缺清单时保留导入入口。 |
| 设置与帮助 | 与指挥台/复盘共享中英语言，保存大厅字号与减少动效偏好，支持网页全屏与明确的失败反馈，说明键盘导航与当前战局行为。 |

大厅首次打开、切页、刷新、修改偏好只进行GET或本地偏好更新，不自动创建、暂停或推进战局。当前局按原倍速运行；进行中的进度仍由当前服务持有。课程预览不包含答案或服务器检查点。

开始任务或训练必须经过原生确认对话框：显示目标任务、席位、种子和暂停开局，说明会替换当前共享战局，当前进度不会另存；结业记录和复盘档案保留。默认焦点为“返回”，Esc可取消，提交期间阻止重复请求并标记忙碌。请求失败保留对话框，提醒刷新当前战局、确认创建结果后再决定重试，不自动重发创建请求。

任务通过服务返回的`file`定位源文件，解决`Tattletail`公开ID为`tattletail_1991`、文件为`tattletail.json`的差异。新局统一请求`speed:0`。随机种子允许空白（沿用想定），或0–9007199254740991的安全整数，不将浮点、科学计数法或精度丢失的数值传入服务器。

## 组织与界面依据

使用现有海军指挥台色系和NASA历史卫星合成影像，不添加未实现的匹配、房间人数、账号、云存档或联机大厅。桌面采用左侧导航与内容舞台；手机导航保持可见，继续指挥优先出现在首屏，长简报与课程正常纵向滚动。

参考 [Xbox XAG112：UI navigation](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/112) 的一致路径、可预测焦点、键盘操作和返回入口，以及 [XAG114：Context and orientation](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/114) 的上下文提示原则（核查于2026-10-19）。本轮实现相应菜单设计与检查，不把参考指南称为认证或宣称已满足其全部辅助输入要求。

`lobby-model.js`负责种子、任务路径与复盘条目校验；`lobby.js`负责读取、预览和明确提交；引擎仍通过原API裁决。没有修改规则、概率、数据库或训练核验逻辑。

## 元数据与本地媒体

`web/lobby-catalog.json`由`scripts/build-lobby-catalog.py`根据实际想定生成，记录时限、初始兵力数量、默认种子、参谋配置、影像标记和源文件SHA256，不包含战局真态。修改想定后运行：

```powershell
python scripts/build-lobby-catalog.py
node --test tests/*.test.cjs
```

大厅以`/api/scenarios`为存在性依据，元数据缺失时明确显示未标注的时限。`web/replays/`保留Git忽略策略。可选的`web/lobby-local.json`也不入Git，可配置本机教学播放器：

```json
{"tutorial_video":{"url":"http://127.0.0.1:8796/?voice=unclefu-v2"}}
```

缺配置时隐藏录像入口；只接受HTTP的localhost/127.0.0.1链接。本机录像与复盘档案不会随源码推送。新机器可按复盘文档导入自己的档案。

本轮验证：32项Node测试、4份JS语法与diff检查通过；42项浏览器交互检查通过，0页面错误，8795监测写请求0。真实新局/课程在8797验收，测试服务已停止。未修改引擎，本轮没有重跑历史Rust111测试。

PVE 对手（2026-10-19）：新任务表单的“对手”三选一——人类红方（热座）、状态机 AI（PVE）、LLM 参谋（Agent）。选择 PVE 时启动请求带 `automated_side:"Red"`，服务端用 `doctrine::orders` 规则参谋指挥红方（仅读本方观察，每 30 模拟秒决策一次：CAP/反潜直升机定时放飞、有合格接触时定期突击）；可与“我的助手”（半自动建议/全自动托管）叠加。规则参谋确定性：同想定+种子+参谋的 `/api/selfplay` 重复运行 digest 一致；倍速只改变推进吞吐，不改变决策内容。
