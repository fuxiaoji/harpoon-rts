# 引擎架构

## 分层

```
┌────────────────────────────────────────────────────────────┐
│ 客户端：web UI │ LLM 参谋 │ MCP 客户端(大模型) │ RL (PyO3) │
└───────────────┬────────────────────────────────────────────┘
                │ 仅能看到 observe() 投影（双盲）
┌───────────────▼────────────────────────────────────────────┐
│ harpoon-server  HTTP/WS 权威服务                            │
│  · 10Hz 节拍 × 时间倍速(0–512×)  · 指令信箱(单次生效)        │
│  · CommandStaff trait（启发式 / OpenAI 兼容 LLM）           │
│  · /api/selfplay 确定性 rollout + 状态摘要 digest           │
├────────────────────────────────────────────────────────────┤
│ harpoon-core  确定性引擎（无 IO、无时钟、serde 全量可序列化）│
│  sim::tick：指令 → 移动 → 航空 → 武器 → 火灾 → 传感 → 清扫 → 胜负 │
│  world(BTreeMap 全序) · sensors(接触簿) · weapons(防御链)    │
│  damage(子系统关键表) · air(甲板周期) · rng(xoshiro256**)    │
└────────────────────────────────────────────────────────────┘
```

## 确定性契约

1. 单一主 RNG（种子派生），子系统不共享流：`world.scope_rng(实体, 用途)` 派生
   子流（对父状态只读、与调用顺序无关），扫描顺序变化不会扰动其它判定。
2. 所有容器 `BTreeMap`/`BTreeSet`；三角函数自实现（Taylor + 象限化简），
   跨平台位级一致。
3. 复盘 = 想定 JSON + 种子 + 指令日志。指令单次生效（RTS 语义：命令即命令，
   航线/航速等作为实体状态持续）。

## 双盲裁判模型

- 每方一个 `SideState.contacts` 接触簿。接触 = 敌实体 `about` + 持续误差向量
  `offset`（按 (seed, 实体) 派生，生命周期固定）+ 跟踪质量 `quality`。
- 客户端显示估计 = 真值 + offset·(1-quality)²，并按估计航向/航速航位推算。
- 传感器层级：雷达（RCS 档 × 挂高视距封顶 × 干扰折减）、ESM（仅测辐射源，
  方位线误差 22nm）、目视（气象/昼夜）、被动声纳（基距 × 航速因子 × 噪声档）、
  主动声纳（探测即反暴露，ping 被 1.6× 距离内敌方被动阵列听到）。
- 武器发射闪光（launch flash）给敌方一个短促低质量定位——齐射即暴露。

## 武器裁决链

- 掠海弹：飞行（8m 参与视距计算）→ 8nm 守方自动箔条（破坏雷达跟踪）→
  4nm 箔条诱偏（45%）→ 1.8nm CIWS 拦截（每弹一波）→ 终局 Pk（箔条未诱偏×0.45）。
- 防空弹：HomingAir 投射物，饱和齐射 Pk 递减，飞机箔条 ×0.85。
- 鱼雷：直航 enable_range → ±40° 锥角获取（主动 3.5nm/尾流 2.0nm）→
  1.2nm 内守方诱饵 55% 诱偏（诱偏后抵点重搜）→ 终局 Pk（高航速目标 ×0.85）。
- 舰炮：即时裁决，射界带（舷侧 1.0 / 象限 0.73 / 艏艉 0.33）× 距离带。
- 损伤：hp 池（官方 DP 量级）+ 关键命中子件表（动力/雷达/声纳/火控/炮位/
  火灾/弹药库殉爆），火灾每秒掉血至自熄或沉没。

## 为什么这些接口长这样

- `observe()` 单一读入口：任何客户端（含 LLM/RL）拿不到真值，杜绝作弊面。
- `Command` 是 serde 枚举：HTTP/WS/MCP/Python 全部共用同一 JSON 形状。
- 事件带 `Visibility`：`All | Side(Side) | Referee`，服务端按连接过滤，
  裁判事件永不外流。
- RL 吞吐：release 下 ~75k tick/秒/核（20 实体量级）；`/api/selfplay` 与
  PyO3 环境返回同一 digest，训练与线上行为一致。
