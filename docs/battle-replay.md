# 战局复盘

从指挥台上方“战局复盘”打开独立的 `replay.html`。页面只读取静态档案，不连接游戏 WebSocket，也不调用战局 API；播放、跳转、切换上帝视角不会暂停、推进或重置玩家的进行中战局。

## 使用

- 蓝方/红方：该方记录的己方单位真态、当时接触估计、当时允许接收的事件。敌方未探测单位不显示，不借用另一席的接触编号或识别结果。
- 上帝视角：合并双方各自的己方真态，按阵营着色；战报包括档案里保留的双方可见事件。地图下方分别显示双方实际样本时间。
- 播放/暂停、1/30/60/300/1200倍、拖动时间轴、上一/下一记录、上一/下一事件、精确时间跳转。空格控制播放，方向键逐记录；输入框和按钮内保留原本键盘行为。
- 点击海图或单位选择器查看舰体、速度、弹药与任务。滚轮/按钮缩放、拖动平移、兵力/全战区聚焦、卫星/网格及选中目标的已记录航迹。
- 战报可按关键、命中损失、航空、探测或全部筛选，也可搜索。点击战报定位其模拟秒；详情复用现有中英裁决解释，并保留可展开的原始记录。
- 导入 `.json` 或 `.json.gz`；导出不含派生索引的 `.replay.json`，可再次导入。文件结构、己方所属、接触字段、事件可见性与大小限制均校验；失败保留当前复盘。语言沿用指挥台的本地偏好。

## 部署与档案格式

不用重新构建或重启 Rust 服务；现有 `ServeDir` 即可提供新增页面。大档案属于本地产物，`web/replays/` 被Git忽略，源码提交不携带录像、模型或玩家记录。部署清单缺失时显示导入入口，不生成示例战果。

本机制作包：`E:\CodexBuilds\harpoon-replay-20261019`；已部署档案约874KiB（gzip）。首次在其他机器使用时，从导出文件导入，或将 `catalog.json` 与对应档案放入 `web/replays/`。

从本局原始证据重新导入（Python标准库）：

```powershell
python scripts/import-observation-replay.py `
  --evidence 'E:\CodexBuilds\harpoon-hotseat-lesson-20261019\evidence' `
  --provenance 'E:\CodexBuilds\harpoon-hotseat-lesson-20261019\source-version.json' `
  --output 'E:\CodexBuilds\harpoon-replay-20261019' --deploy web/replays
```

该脚本专用于这局教学记录，校验两席均已结束、事件序号连续、重复事件一致及所属阵营；记录输入哈希、导入统计和可重复的gzip输出。通用播放器接受版本1的 `harpoon-observation-replay` 格式：`title`、`frames.Blue/Red`、`events`，可选 `theater`、`source`、`bookmarks`。每帧有 `tick/units/contacts`；事件有 `seq/tick/event/vis`，`vis`为`All`、`Referee`或`{Side: Blue|Red}`。

这一交付提供档案导入、查看与再导出；未来进行中战局的自动全量录制、命令重演和逐秒World校验继续在项目计划内单列。
