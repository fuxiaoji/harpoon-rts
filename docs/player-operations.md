# 当前RTS操作说明

顶部“怎么玩”会暂停战局并打开中英双语说明。关闭后保持暂停，玩家自行选择倍速。它描述当前代码，不代表完整桌面规则已实现。

从前端新开或重开想定默认暂停，先读初始态势再选择倍速，避免原先默认60倍速在读界面时推进交战。

## 开火

| 操作 | 行为 |
| --- | --- |
| 点选C接触 | 查看情报，不攻击 |
| 人工射击1发 | 每次下达一次性1发命令；暂停只排队，运行后处理；回执不保证实际发射 |
| 指定目标自动交战 | 持续交战，自选可用武器；冷却及条件允许后再次射击，即使自动选敌关闭也会执行 |
| 自动选敌开火 | 没有可解析指派时自动选择接触交战；不是完整战术参谋 |

停止主动自动交战需要取消指派并关闭自动选敌。已发射武器不会被撤回；点防御等底层自卫仍可能反应。实际射击以武器释放、舰炮射击等执行事件为准。当前服务的普通命令回执仅表示排队，尚无统一执行失败回执。

实现依据：`crates/harpoon-core/src/weapons.rs` 的 `fire_control_scan`、`fire_salvo`；`web/app.js` 的 `issueAssignTarget`、`issueFire`；`crates/harpoon-server/src/main.rs` 的 `command_handler`。

## 探测与战报

时间推进时传感器自动扫描，当前RTS基础周期4模拟秒（`world.rs::SENSOR_INTERVAL_TICKS`）。主动声纳需单独开启，可能暴露自身。雷达/目视受视距、目标高度及其他已实现条件约束；ESM和被动声纳的接触可能只有方位。接触质量不是命中率，型号识别也不等于精确定位。

概念来源：Harpoon V 2026-01-01英文版§5.1–5.1.1，印刷5-1/PDF40。按仓库规则技能先检索核心RAG，再视觉回看原页。本轮未转录新表或修改探测常量；现有改编与缺口见 `design/adaptations.md`、`compliance/rules-audit-001.md`。

战报按“发现→发射→拦截→命中→损伤”阅读。规则事件显示含义及可解析的中文数值，原始英文在下一层。未知格式明确标记未提供中文数值解释，不猜译结果。D20为20面骰；系统能力1.00代表完整能力，不能与舰体耐久混读；数据链转发并不代表攻击。

`web/combat-help.js` 按既有引擎事件格式提供解释，包括近程破片、数据链、交叉定位、损管、拖曳声纳、电池、浮标、缠斗、跑道、尾流与已声明改编。语言切换会重绘现有事件，并保留外层展开状态及滚动位置；只处理当前玩家可见的事件。

## 大想定与AI

`scenarios/pacific_storm.json` 预置航速、航线、护航跟随和战斗单位自由开火，双方因此能持续自主行动。普通实时主循环没有持续调度 `HeuristicStaff` 或 `OpenAiCompatStaff`；启发式参谋用于自对弈，单步AI接口单独调用参谋。首批教学另有受控防御课对手，不能等同完整自主作战AI。
