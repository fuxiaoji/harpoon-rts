# 导弹末段与残留航迹修复（2026-10-19）

用户报告：导弹在舰艇附近反复蠕动，未见损伤。只读检查玩家8795，不重置或推进其战局。

## 已核实的原因

- `HomingAir` 成功后只销毁了拦截弹，未销毁目标导弹或飞机；成功记录还发给了目标方，并引用拦截弹的接触号。现改为实际销毁空中目标、向发射方报告其目标接触号。
- 无上限的一秒飞行步长可能跨过末段半径，下一秒反向追赶。现每步最多抵达制导点，保留原速度、末段半径和概率。
- 受骗反舰弹不断追同一个诱饵点，仍检查原舰位置，可能来回运动直至燃料耗尽。现抵达诱饵点即结束，受骗期间不再攻击原舰。
- 在途列表先收集再遍历；同一tick先被拦截的导弹仍可能执行后续更新。现每次更新先检查存活。
- 敌方接触是有误差的情报记录，死亡不会自动向全场公开。未更新航迹会外推，失联记录最长保留900秒。确认SAM/CIWS拦截后只清除防御方对应接触；其他方记录按原情报机制衰减。

修复没有提高命中率或降低防御。截图中的附近符号不能证明导弹已到达真实舰位。
