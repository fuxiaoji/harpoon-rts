# Harpoon V 核心规则—引擎四联审计

审计日期：2026-08-22

## 结论

当前不能认定“三本核心规则的所有结算表格和规则都已输入引擎”。三本资料已进入可检索语料工程，但“可检索”不等于“可执行”。引擎目前只对反舰导弹攻击、部分软杀伤、导弹飞行、部分防空参考数据、部分舰艇损伤与胜负判定形成实现；大量章节仍为 `partial` 或 `blocked`。

完成判据固定为四联证据同时成立：

1. `Source`：原 PDF 页、章节/表名、版本和视觉复核记录；
2. `Data`：完整表格/公式、条件、修正、优先级与舍入规则已结构化；
3. `Execution`：引擎存在实际调用路径，并输出查表输入、修正、骰值和结果；
4. `Tests`：边界、非法输入、确定性和至少一个跨模块案例通过。

仅有 OCR、RAG 命中、JSON 片段或 UI 展示的项目不得标为 `tested`。

## 阻断规则

- 自动候选清单在 `resources/rag/table_candidates.jsonl`，其默认状态为 `candidate_requires_visual_check`。

- 权威版本仍按 `agent.md`：英文 2026-01-01 数字更新版优先；中文三本用于核心检索、理解和交叉核验。
- 后续任何“全部完成”结论必须由逐表注册表给出，且所有基础规则行均为 `tested` 或有来源支持的 `not_applicable`。
