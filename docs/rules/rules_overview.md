# Harpoon V 规则理解总览

## 定位与边界

Harpoon V 是 1955 年至今的现代海战战术级模拟，基本单位是单舰、单艇、单机/机群及相关陆上目标。它覆盖水面、水下、航空攻击，舰炮、巡航/防空/弹道导弹、电子战、反潜战、损伤和水雷战；不覆盖两栖突击、拖带和航行补给等非战术演化。

设计重点不是复刻每个操作流程，而是模拟指挥员在不完全信息下的决策：寻找、识别、建立火控解、分配武器、评估风险并控制损伤。

## 核心假设

1. 找到敌人通常是海战最困难的部分。
2. 现代舰艇系统脆弱，单次有效命中可能形成任务摧毁。
3. 喷气机和高速导弹使反应时间极短。
4. 公开来源数据存在不确定性，游戏值应被视为一致化模型参数，而非绝对真实性能。

## 时间与阶段

### 中间回合

- 时长 30 分钟。
- 只进行计划、移动和探测，不允许战斗。
- 当单位进入潜在探测范围时，将移动回退到该中间回合开始位置，转入战术回合处理探测。
- 玩家可因威胁或态势变化主动转入战术回合。

### 战术回合

- 时长 3 分钟，非格斗状态航空单位亦可使用。
- 双方同时执行：`计划 -> 移动/抵达武器结算 -> 计划射击 -> 探测 -> 反应射击 -> 火灾/进水与损管结算`。
- 只能对已探测目标作出反应；玩家本人知道某单位存在，不等于其受控单位获得该情报。
- 计划射击阶段发射的面舰导弹/鱼雷因本回合移动已结束，下一战术回合才开始移动。

## 对软件架构的直接约束

- 回合系统必须支持 30 分钟与 3 分钟时间步切换、回退和多群组异步时间推进。
- 命令先收集后统一裁决，所有玩家操作不能立即修改权威状态。
- `world_state` 与每方 `observation` 必须分离；接触应具有未知、方位线、探测、分类、识别、丢失等生命周期。
- 火控解、传感器接触和玩家知识是不同对象，不能用一个“可见/不可见”布尔值代替。
- 导弹、鱼雷、火灾和进水都是跨回合持续实体/效果。
- 随机裁决必须记录使用的表、修正值、掷骰和结果，以便科研复现。
