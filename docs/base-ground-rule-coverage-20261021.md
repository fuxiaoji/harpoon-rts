# 基地资料、对陆规则与火箭军覆盖核查（2026-10-21）

结论：现有资料包含部分基地示意位置/驻地编成、通用陆上设施数据，以及机场/港口/弹道导弹的作战规则；没有因此形成中国和琉球每一座真实基地的完整设施卡，也没有完整火箭军战役模拟。当前Rust实现仍有明显缺口。

本次为只读资料与源码核查，不生成现实基地坐标或设施目标清单，不修改规则、想定、服务和战局。所有页码中“PDF页”均从1开始；印刷页码单列。

§11.7的标题和组件抽选程序明确是**舰炮炮击港口**，不能把该D100表无条件套到巡航导弹精确攻击。港口内已定义的点目标要结合§11.1、§11.2/§11.3/§11.4及其目标数据处理。

这些是**通用部件数据**。它们可以给虚构机场/港口建立有规则依据的设施类型；具体真实基地有多少部件、各部件在哪里及现状如何，不能由通用表自动得到。主规则§11.1也明确由想定提供可攻击目标的尺寸、装甲和DP。

## 4. 当前项目实现情况

本轮静态复核`crates/harpoon-core/src/rules/strike.rs`、`db.rs`及演习来源账：

- 现有Rust机场/港口仍使用通用Base实体。`runway_ops`/`radar_ops`每tick由同一个`hp/hp_max`推导；有甲板的基地以剩余HP比例延长航空周期，尚未完整按跑道切断数与飞机类别执行11-2表。
- §11.1的组件功能、港口泊位/坞门/泵站等独立效果，没有因此被一个Base血量条完整表达。
- `WeaponKind`没有完整弹道导弹类型；尚未发现DF-21D/DF-26B与专门ASBM/BMD/对陆CEP程序的完整生产链。`AswBallistic`是反潜火箭分支，不是火箭军弹道导弹已实现的证据。
- 已有原问题R-021与相关第14章审计继续适用。本轮仅核对资料覆盖，不修改裁决、不追改旧战果。
