# 琉球震潮基地数据与替代约定

## 数据结论

现有 Harpoon 数据库没有嘉手纳、那霸、普天间的完整“机场设施卡”。数据库可提供航空器、武器、部分驻军和那霸航空编制线索；基地跑道取公开官方资料，其他设施依想定同类数据建立。

## 公开数据

- 嘉手纳：两条 12,000 英尺跑道，换算 3,658 米；规则表按不超过实际长度的 3,000 米列查表。
- 那霸：3,000×45 米与 2,700×60 米两条跑道；后者按 2,000 米列查表。
- 普天间：当前跑道 2,740 米；按 2,000 米列查表。
- 日本数据库确认那霸第9航空团、204/304飞行队及西南航空方面队等编制线索。

## 想定同类组件

油库采用第11-3页 `Magazine Bunker` 的 E级、60 DP、装甲16作为受保护POL设施同类值。基地防空采用 `SAM or SSM launcher` 与 `Search or MFC radar` 通用目标行；普天间航空器存储采用 `Medium Hangar`。这些条目全部标记 `scenario_assumption`，不代表真实数量、精确位置或秘密部署。

基地包位于 `data/platforms/ryukyu_2025_core.json`，想定仅通过 `data_packages` 引用；规则表位于 `data/rules/airfield_tables.json` 与 `data/rules/land_strike_tables.json`。

## 当前可玩边界

当前版本可执行 CJ-10 对陆巡航导弹的命令、在途状态、11-3命中查表、D100、穿透门、52+D6毁伤、跑道切口和50%功能失效。航空器起降、挂载、空袭、基地防空拦截和跑道修复仍处于阻断状态，不能把本子集称为完整航空战役。
