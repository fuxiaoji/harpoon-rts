# 规则全量录入覆盖率矩阵（rules-coverage-matrix）

- 基线：`14-2.HpnV_Rules_1_Jan_26.pdf`（2026-01-01 英文数字更新版，14 章）；附：玩家手册（30./2-2.）、扩展损伤手册（3-2./3.）、Admiralty 数据库卷（4-9/11/16-30 等）、官方想定卷（19/22/23/24 等）。
- 章节结构来源：规则书目录（PDF p7-13，经页级索引 `resources/rag/harpoon_rules.sqlite3` 提取）。
- 引擎状态核对基准：commit `827348b`（含 `339135c rules: apply second compliance audit`）的 `crates/harpoon-core/src/` 实读代码。
- 状态三值：**已录入**（有引擎结算路径）/ **改编录入**（以声明的方式实现，指向 `docs/design/adaptations.md` 行号）/ **未录入**。
- 行计数口径：每行 = 一个"小节组"（机制上不可分的小节合并；如 5.2.9.1-4 计 1 行）。带 \* 的改编录入 = 已实现但 `adaptations.md` 编号表中**无对应声明行**（文末 §3 列出）。
- 未录入优先级：**P0** 战术核心（缺了核心裁决环失真）/ **P1** 增强（影响平衡或保真度）/ **P2** 可延后（边角或可选规则）。
