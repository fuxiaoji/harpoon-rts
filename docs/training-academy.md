# 训练学院与双语界面 v1

这是当前 **RTS 改编配置**的第一批可玩教学。采用递进任务、控件定位、三级提示、检查点重试、实际操作判定、知识检查与结业记录。它不等于 `plan.md` 中全部 18 个课程包及严格桌面规则已完成，也尚未进行陌生玩家试教。

## 玩家入口

2026-10-18 试用反馈修正：加入默认开启的“指挥教官”。当前控件周围有金色高光、背景压暗及连线，旁边解释具体操作；切换目标时自动滚动到控件。第一步的阅读确认也有高光。实操时讲解栏默认收起，海图与操作区保持可见；可以随时展开讲解。

填写参数、下达命令、推进执行是连续子步骤。正确输入或确认默认值后指向下达按钮，收到匹配的成功排队回执后才指向单步执行；实际目标完成仍由原权威服务器判定。错误数值会提示要求，检查点重试会重置子步骤，刷新后会先引导重新选舰/接触。教官提示不替玩家填写参数或执行命令。

点击提示右上角×或按Esc可暂时收起；教学栏的“显示操作高光”可重新开启。高光在目录、自由指挥及结业时自动隐藏。收起讲解后若当前操作藏在其中，会先指向“展开讲解”。

打开顶部“训练中心”，选择课程，再点“开始本课”。开始会重置该服务器当前战局；目录内有明确说明。教学栏可以收起，控件定位可以滚动到操作区域。实际操作步骤不能靠“继续”跳过。

顶部及课程目录都可以切换“简体中文 / English”，默认中文，浏览器记住语言。切换即时更新课程、界面、海图文字及常用战报，不重开战局。型号 ID、武器 ID、地名、源规则引文及展开后的原始裁决详情保留原文，方便追溯。

## 判定与恢复边界

- 课程由 `data/training/courses.json` 定义，编译入服务器。公开目录不含答案；原文件在静态目录以外。
- 客户端提交课程动作时携带 attempt 与 step，拒绝旧页面动作。服务器检查己方单位和可见接触。单位/接触选择与阅读确认属于客户端动作；机动、交战、反制和航空目标还须由引擎状态或事件证明。
- 开始课程会将训练双方设为限制开火、无自动目标、关闭自动箔条。该姿态是公开的想定设计。炮击训练还要求人工命令与炮击事件共同出现，自动交战不能代替人工操作。
- 防御课对手通过自己的 observation 和正常开火命令发射单枚导弹，不根据蓝方隐藏真值发射。原有点防御保留。波次未形成练习机会时可重试，不把它算作玩家战术失败。
- 命中、落空、损伤、传感器与回收走现有 `harpoon-core`，没有强制命中或修改概率。完成过程目标不保证战术胜利。
- 实际目标达成会在同一个 tick 暂停；“启动时间”练习继续运行，等待下一步主动暂停。
- 当前步骤检查点在服务器内存中保留完整 World（含RNG、弹药、事件）；重试恢复并清空未执行队列。刷新页面可续接服务器仍在运行的课程。**服务器重启后只恢复结业记录，不恢复进行中的世界/课程。**
- 结业记录是本地单服务器共用档案，不是账号系统。`HARPOON_TRAINING_PROGRESS` 指定 JSON 路径；默认 `tmp/training-progress.json`。文件带版本号1，同目录临时文件完整写入后替换。写入失败会在结业面板提示。
- 训练状态只返回己方ID、进度与证据摘要；完整检查点和敌方世界不下发。原服务允许自由指挥模式换边，这是现有本地沙盘能力；此版本没有增加多人账号鉴权。
