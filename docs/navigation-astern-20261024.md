# 3.1.3 倒航实施包

当前已实现窄范围生产路径，等待统一绿测；不可称为倒航全机制或第3章完成。首轮真实生产红证据为`artifacts/rules-closure-20261024/validation/astern-airdrop-red.log`：本目标12项中1绿11红，来源配置负例原已通过，11项缺失执行如实保留。

先执行核心RAG“倒航”“舰船 加速”“轮机 致命损伤”，再直接从只读英文2026-01-01原PDF重新渲染、视觉核对PDF24/印刷3-2的Ship Speed Change表及PDF25/3-3 §3.1.3。来源哈希、原页、检索结果和逐项数值在`artifacts/rules-closure-20261024/astern/`。

来源规定水面舰倒航最大速度为最大前进速度一半，潜艇不得超过5kt；倒航加速度为前进一半。有已部署拖体时，每个实际倒航战术回合有50%拖体全损，另有10%缆缠桨，按Engineering critical处理。两骰独立、按检查前的拖体快照，不以50%失拖体作为10%缠桨的前提，也不能给此处工程critical套用CrashBack的“忽略火灾”例外。

实际保持速度非负，另保存请求方向和实际位移方向，使用既有正常减速制动到零，在下一秒才改变位移方向并按来源倒航半加速度加速。潜艇静航限制仍相乘。此连续制动/逐秒积分是RTS改编，原书未规定一秒级换向时间。倒航命令退出Follow、清空航点；未知倒航改向、舵/舰桥损伤组合、真实多拖体、部署/回收中缆索或实际扫雷gear存在时均进入pending，不借前进转向表自动处理。

速度先取既有真实损伤/动力/潜深限制、作者绑定无损最高速和已绑定潜艇水上最高速的最低值。水面倒航将该前进能力减半，潜艇取该能力和5kt较低者；然后与按无损最高速计算的海况限制、战备/装备限制取最低。海况5/D尺寸/作者无损30kt的倒航上限仍是15kt，不再次减至7.5kt。另有来源Ford首417DP损伤后24kt、倒航12kt边界，作者D尺寸只用于控制加速表，并不声称Ford真实尺寸D。

实际反向扫掠经过海岸守卫后才积分；成功位移后在本战术回合首次投原生独立D100两骰，按`tick/180`窗保存。不成功的海岸段、静止和无已部署拖体均不投；重复倒航命令不重投。已绑定的单一拖曳声纳/VDS实际置lost/停止部署，单一拖曳诱饵实际置Destroyed。缠桨复用根代理提供的`damage_runtime::astern_cable_engineering`，保原电力D6、工程速度分档和D6-2火灾，无普通武器Impact/DP/BDA；未知工程元数据保留骰和pending，不继续逐秒加速或重抽。风险兑现是在第一次真实反向位移后这一RTS阶段，不声称原书指定该秒级时序。

首轮12例之后补齐3项实施边界：真实来源损伤档与半速组合、反向跨过薄陆地段的扫掠/零骰、作者初态单一拖曳声纳的真实失能。当前目标共15例，新增3例不冒充已留下原首跑红。原12例仍涵盖半加速与反向位移、舰/潜艇上限、海况组合、两向过零制动、逆向改向待裁、四种原生两骰组合与防重掷、次战术回合、真实双拖体待裁、完整World保存与本方投影、静止/无拖体及缺配置。Hull/推进配置、已部署声纳和诱饵库存均标作者假设，不将Ford/Virginia当已核实际倒航配置。

未完保持：倒航转向、复杂缆索/扫雷具、全平台绑定、CrashBack、碰撞/搁浅及第3章其他机制；没有新增HTTP/UI/LLM/FSM验收声称，接口由根代理另行接入。旧冻结证据未更改，普通未绑定或旧profile不启用此分支。
