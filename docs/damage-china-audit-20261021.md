# 中国武器与福特号损害链核查（2026-10-21）

本报告回答当前工作区 Rust RTS 的游戏数值问题。未修改裁决、武器库、想定、运行服务或历史战局。旧 Python 原型不用于本报告结果。

2026-10-21 来源解释更正：英文§14.1.5说明导弹损伤栏DP后的骰式表示**附加关键损伤次数**，不是额外舰体DP；空射YJ-12也须同时区分高空48+D6与掠海46+D6两行。下文相应来源说明已明确更正，原沙盒协议、统计和历史战果保持原样。扩展审计见[损伤全链原规则核对](damage-rules-audit-20261021.md)。

## 结论与统计口径

当前 `us_ford` 为 **1667 HP**。中国卷中有 23 项 `targets.surface=true` 武器定义，另有中国舰艇使用的共用 `ciws_30mm`，共 **24 项**；其中 `cn_akd88` 仅有武器定义，没有中国卷平台挂载，其余 23 项有中国卷挂载。某个想定是否配置了携带平台、该挂载与库存，仍应另外检查，不能将数据库条目数当作单局可用武器数。

表中有两个不同的量：

- **名义扣血次数**：`ceil(1667 / weapon.damage)`。关闭随机浮动、关键损伤与持续损害，只按固定基准伤害扣血。它不是严格的平均首次击沉次数。
- **损害沙盒平均命中次数**：每武器 20,000 个种子，满状态、满防御弹库的福特号；每模拟秒强制发生一次成功命中，固定使用 `Some(90.0)` 进入同一装甲分支；调用生产 `damage_ext::step → damage::apply_hit_at → damage::update_fires`，直至 `alive=false`。计入当前关键损伤、弹药殉爆、火灾、进水与损管；不执行目标防御射击，不模拟探测、飞行、命中检定、攻击方库存与装填。这是人为固定的数值实验协议，不是武器实际射速或交战方案。

全部数值为**成功命中后的游戏用量**，不是发射需求、某场战斗的胜率、现实性能或严格桌面规则结果。发射量须先固定合法交战条件、双方观察与航迹、拦截/诱饵/库存、命中检定和到达时间序列；鱼雷还可能重新攻击，因此不能把所有分支简单统一成 `命中次数/pk`。

均值的抽样标准误保存在 JSON 中。导弹与鱼雷约为 0.008–0.302 次，最低伤害舰炮约 0.845–1.088 次。所有武器使用相同种子集合，不能把跨武器结果当成相互独立的实验样本。

## 当前损害执行链

入口是 `crates/harpoon-core/src/damage.rs::apply_hit_inner`：

```text
variance = U[0.85, 1.15)
damage = weapon.damage × variance × armor_factor(target.class, kind, bearing)
hp_after = hp_before - damage
p_critical = 0.10 + 0.30 × (1 - hp_before / hp_max)
若 hp_after > 0，最多触发一次常规关键损伤；舰首/舰尾另有10%轻损伤分支
关键损伤之后检查当前HP，<=0则sink
```

损伤概率取**本次命中前**的 HP 比例：满血 10%，半血 25%，接近零血约 40%。并不使用每阶段损伤/剩余DP的正式损伤比率表。

`damage_tables::armor_band` 只识别 `cvn`、`ddg_aegis`、`mgb`、`pb`；`us_ford` 落入 `NONE`。在本实验的固定分支，导弹、炮、鱼雷倍率均为 1.0。通用 `cvn` 的鱼雷 0.75 倍率没有应用到具名福特号。即使落入 `NONE`，现代码的舰首/舰尾鱼雷分支仍额外减半；不能概括为福特号所有方向均无修正。书面装甲与抗雷结构也不是这些估算倍率。

主关键损伤按武器种类选择 Gun/Missile/Torpedo/Bomb 四列。武器关键损伤从有弹挂载中按最小 `mounts` 选取一项，非 Bomb 列有 10% 概率直接将整舰 HP 置零，否则清空该项弹药。它没有区分福特号甲板上发射器与甲板下弹药库。此简化会使小伤害武器的平均值明显低于名义扣血次数，不代表小口径武器具有相应现实效果。

火灾每秒扣 0.05 HP；进水每秒扣 0.15 HP。一次火灾加60秒、累计封顶180秒；进水加120秒、封顶300秒。损管每秒80%概率获得1点进度，火灾60点、进水120点，进水优先；每次新命中将进度清零。最后命中后300秒开始每60秒恢复系统值0.2；这不会恢复舰体HP。单个60秒火灾/120秒进水在没有追加时至多扣3/18 HP，可能提前受控；不是按航母总HP百分比扣血。

生产 tick 顺序为 `rules::step → weapons::update_weapons → damage::update_fires`，沙盒保持了其中相关的损管、命中、持续损害顺序。

## 与完整规则/数据书的实质差异

1. **航母关键损伤列错误。** 英文2026 PDF128 / 14-2注释和扩展表PDF5末注明确：导弹攻击航空舰船按该舰种列。当前只按武器类别选Missile列；没有使用航空舰船列（扩展表PDF7）的飞行甲板、机库、弹药/燃料库分布。代码只在Bomb列相关分支写入`flight_deck_hit`；全核心检索未发现航空勤务读取该标志，不能把注释中的“禁止起降”当成已执行效果。
2. **关键损伤次数不是正式比率表。** 英文§14.1.2 / PDF127、129要求阶段伤害除以结算后的剩余DP，向下取比率行，再掷D6决定次数；当前是每次命中按既有损伤程度取10%–40%的至多一次判定。也未完整执行小口径适用表与星号部位穿甲前提。
3. **导弹附加关键损伤缺项（来源解释更正）。** §14.1.5 / PDF130说明附件`38+D6/2`、`33+D6/2`、`48+D6`是普通DP与附加关键损伤骰的组合，后面的骰子不能加进舰体扣血。当前只保留普通DP标量、另乘±15%浮动，没有独立执行这些附加关键次数、符合条件的自动火灾及无骰式武器的例外。
4. **鱼雷伤害与抗雷结构不完整。** F-1/F-2的对舰值Yu-6/Yu-10=141、Yu-9=128、TE-2-01=150，当前依次为120、110、128等对舰/对潜折中值；53-65K保留150。福特舰卡是装甲`0/5/315`，§14.1.7 / PDF130–131需区分引信、深浅与分舷抗雷结构消耗，不能替换成统一百分比护甲。自动进水等亦非当前完整实现。因此不能简单换用141就声称得到严格规则用量。
5. **YJ-91的适配差异尤其大。** H-4为D6+2、反辐射及空爆；当前`damage=10`，普通Ascm对舰。AKD-88的H-3伤害为36+D6/2，当前只有36且没有中国挂载。
6. **H-6J并非独立空射YJ-12配置（来源更正）。** 中国卷PDF82/印刷H-4空射YJ-12有VHi巡航216海里、48+D6、1719节和SSkim巡航110海里、46+D6、1320节两行，Pen9，备注D另有高空发射及末27海里掠海1585节条件。D-1舰射YJ-12A/B为高空162海里/48+D6与掠海54海里/46+D6两行，Pen13。现`cn_yj12`被舰艇与H-6J共享为216海里/48/SeaSkimmer混合配置，不能将其沙盒结果代表各变体；也不能简单说48必错或216没有书内来源。
7. **同秒随机数复用。** `World::scope_rng(target_id,"damage")`由tick、目标和用途派生且不推进主流；同一秒同目标每次调用重置同一子流，没有弹体/命中序号。实测两次YJ-18伤害均31.759776677543616。常规关键损伤的抽样值也关联，但阈值会随HP变化，不能说所有关键损伤结果必然相同。本次每秒一次命中只定义了便于审计的分支，不代表任意齐射统计。

以上为代码和原页审计结论，尚未修复，也不因此修改既有比赛战果。登记于外层`docs/rules/open_questions.md`的R-022至R-024。
